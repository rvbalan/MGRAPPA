# MGRAPPA
Code and Other docs related to the MGRAPPA algorithm: Motion Corrected GRAPPA for MRI

Create folder 'results'
Run in Matlab:
MRI_grappa_motion_correction_MGRAPPA_PAPER.m

The code requires 'ChannelImage_sos.mat' for channel information; and 'sub-02_ses-01_T1w.nii' as raw data.

Program generates a total of 658 files: 7 .csv, 1.mat, and 650 .jpg.
Some files (162) are created in the local folder; rest (496) are saved in 'results' folder
